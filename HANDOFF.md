8 October 2026 Unix write ownership: a host-approved write replaces the file by renaming a temporary file over it, so before this change the new file got the host user's owner and primary group. A test showed a file in a shared supplementary group (`997`) came back as group `1000`, and a world-writable file owned by `65534` became owned by the host user. Now the temporary file gets the existing owner and group with `fchown` before the mode is copied (chown can clear set-id bits).
