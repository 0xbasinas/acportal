MCP storage recovery also passes full-navigation checks for missing ciphertext and an actual encrypted-write failure in an isolated vault. Preference-commit failure, long values and configuration/process death remain unverified.

Emulator fixtures establish the behaviors named above. They do not establish production network reliability, complete real-agent compatibility or release readiness.
