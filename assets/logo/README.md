# ACP Portal logo

A ring (the portal between phone and computer) with a terminal prompt chevron inside. Designed in Penpot (board "50 - Logo / ACP Portal"); these SVGs use the same geometry on a 512 x 512 grid.

| File | Use |
| --- | --- |
| `logo-dark.svg` | Default app icon (near-black tile, mint ring, white chevron) |
| `logo-green.svg` | Android launcher background variant (mint tile) |
| `logo-light.svg` | Light surfaces |
| `logo-mono-white.svg`, `logo-mono-black.svg` | Single-colour mark with no tile, for tray and taskbar icons |

Colours: `#0A0A0A` near-black, `#72D5B0` mint, `#EDEDED` off-white, `#FAFAFA`, `#1F8A64`, `#171719`. Keep the ring and chevron at 36 units of stroke so the mark stays legible at small sizes (16 px shows a ring with a faint arrow).
